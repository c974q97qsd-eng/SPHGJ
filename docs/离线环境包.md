# 离线环境包（完整版 / 轻量版）

> 2026-10-20 打包。分两个版本，**都不进 git 仓库本体**，原因见最后一节。
> 存放位置：项目云盘空间 → `SPHGJ-项目备份/`

## 一、两个包的区别

| | 完整版 | 轻量版 |
|---|---|---|
| 压缩包大小 | **517.5 MB** | **72.9 MB** |
| 解压后 | 1.09 GB | 73.6 MB |
| 便携 Python 3.14（已装全部依赖，免装免 PATH） | ✅ 396 MB | ❌ |
| Playwright Chromium 1223 + headless shell + ffmpeg | ✅ 671 MB | ❌ |
| wheels（30 个离线依赖包） | ✅ | ✅ |
| packages（python-3.14.3 安装包 + WebView2 引导器） | ✅ | ✅ |
| `一键安装.bat` + `安装说明.md` + `_gen_bat.py` | ✅ | ✅ |
| 适用场景 | **目标机完全没网** | 目标机能联网（自己装 Python + `playwright install chromium`） |

名字里的"完整"指的是**运行环境本体齐全**（Python 解释器 + 浏览器内核都在里面）；
轻量版只给依赖材料和安装脚本，Python 与 Chromium 要目标机自己弄。

## 三、完整版部署步骤（无网机器）

1. `git clone` 代码到目标机，例如 `D:\SPHGJ`
2. 把完整版 zip 解压到**项目根目录** → 得到 `D:\SPHGJ\配置环境安装\`
3. 双击 `配置环境安装\一键安装.bat`（做 6 件事：准备 Python 3.14 → 配浏览器路径 →
   离线装依赖 → 校验 6 个关键包 → 检查 .NET → 检查 WebView2）
4. 双击项目根目录生成的 `启动-SPHGJ.bat`
5. **不要把 `配置环境安装\` 删掉** —— 软件运行时依赖里面的便携 Python 和 Chromium

前置组件（系统级，包里没有）：**.NET 6/8/9 任一** + **WebView2 Runtime**（Win10 21H2+ / Win11 自带）。
缺失时桌面窗口打不开，软件会弹原生提示，不会降级用浏览器。

## 四、轻量版部署步骤（可联网机器）

1. `git clone` 代码
2. 装 Python 3.14（用包内 `配置环境安装\packages\python-3.14.3-amd64.exe`）
3. `pip install -r requirements-lock.txt`（**不要用 `requirements.txt`**，范围写法会漂版本）
4. `playwright install chromium`（会自动拉到对应 revision **1223**）
5. 解压轻量版覆盖项目根的同名目录，按需跑 `一键安装.bat` 里剩下的检测步骤
6. `python main.py`

## 五、为什么 1.1G 不放进 git 仓库本体

| 原因 | 具体情况 |
|---|---|
| 单文件硬限制 | GitHub 单文件 **100 MB** 上限，517 MB 的 zip 直接 `push` 会被拒 |
| LFS 额度不够 | git-lfs 免费仅 **1 GB 存储 + 1 GB/月流量**；一个 517 MB 版本就吃掉一半，且每个 clone 都要重拉 |
| 历史不可逆 | 二进制进对象库后压缩不掉，仓库永久膨胀；想删只能 rewrite history + force push |
| 换机体验更差 | clone 1.1G 比"解压一个 zip"慢得多，还依赖网络稳定性 |

**正确做法**：Release 附件（单文件 2 GB 上限，走 CDN，不进对象库）+ 云盘各存一份；
仓库里只放这份说明和 `requirements-lock.txt`。

## 六、更新离线包的流程

```bash
# 依赖有变动后
python -m pip download -r wheels\requirements-lock.txt -d wheels
# 浏览器升级后,从 %LOCALAPPDATA%\ms-playwright\ 复制对应 revision 目录进 ms-playwright\
# 最后重新打包(完整版/轻量版)并更新本文件的 SHA256
```
