# SPHGJ 视频号工具 · 功能说明

> 一句话：**把多个视频号账号的直播数据、作品、评论，集中到一个页面盯盘；一台电脑跑，全公司电脑、手机浏览器都能打开看。**

---

## 1. 它解决什么问题？

视频号后台（channels.weixin.qq.com）一次只能登录、查看**一个账号**。如果你有多个店号，想看"现在谁在播、播得怎么样、评论说了什么"，就得来回切换登录、来回翻页面——账号一多根本盯不过来。

SPHGJ 把这件事变成：**所有账号的数据汇到同一个界面，一屏看完，自动刷新，不用人守着。**

---

## 2. 多账号直播大屏 · 集合盯盘

- **一次接入多个账号**：每个账号扫码登录一次，之后长期保持在线（登录态本地保存）。
- **直播大屏**：所有账号的直播状态、观看人数、点赞、评论流等关键数据聚合展示，谁开播了、热度涨没涨，扫一眼就知道。
- **自动盯盘**：后台定时轮询各账号，开播自动抓取、下播自动收尾；不用再一个个后台手动刷新。
- **评论统一管理**：所有账号的评论汇在一起看、一起处理，详见下文第 3 节。

## 3. 评论管理 · 一个页面处理所有账号的评论

- **实时汇聚**：各账号的评论实时抓到本地，同一页展示；可按账号筛选、按状态筛选（未回复 / 已回复），支持按评论内容和用户昵称搜索。
- **手动处理**：点击任意评论即可「回复 / 删除 / 置顶」；支持批量勾选后一键批量删除（带二次确认，防误删）。
- **关键字自动回复**：配置多条「关键字 → 回复内容」规则，新评论命中即自动回复（同一评论只回一次）；总开关一键启停，规则对所有账号生效。
- **关键字自动删除**：评论内容命中关键字即自动删除（一级 / 二级评论均生效，同一评论只处理一次）；每次自动或手动删除都留有记录，支持搜索与清空，方便回溯。
- **隐藏发出的评论**：开关打开后，由自动评论+置顶、自动回复、手动回复发出的评论会自动隐藏（避免话术外泄与同行窥探），关闭即恢复正常显示。
- **导出 CSV**：评论数据一键导出，便于二次分析或留档。

## 4. 局域网共享 · 一处部署，处处可看

工具跑在一台电脑上（这台电脑负责抓数据），**同一局域网里的任何设备**——别的电脑、平板、手机浏览器——直接输入这台机器的地址就能打开完整界面：

- 老板在办公室看大屏，运营在工位处理评论，互不干扰；
- 数据在**自己局域网内传输**，不经第三方服务器，不外泄；
- 不用每台电脑都装工具、都扫码登录。

## 5. 账号锁定 · 扫错微信自动拦截（本次更新重点）

每个账号都能「锁定」到自己对应的那个微信。锁定之后，万一拿错微信去扫码，工具会当场兜住：

- **当场识别并拦下**：一发现扫码的微信不是该账号锁定的那个（包括「选择视频号登录」页里根本找不到对应账号），立刻中断本次登录，不再让你在错误的列表里点选——从根上杜绝"选错号""凭空多出一个随机账号"。
- **自动清掉错误登录态**：把该账号残留的错误 Cookie 与本地存储文件全部清除，恢复到**全新登录环境**（不必再手动删目录）。
- **弹警告框讲清楚**：明确告诉你「应扫的微信是谁 / 本次扫到的是谁 / 已清理完毕」，确认后原地重新拉起扫码，用正确的微信扫一次即可，不用重启软件。
- **启动时也校验**：如果某个账号现存的登录身份与锁定的微信不符，启动时自动按「未登录」处理并提示重新扫码，避免错号的数据混进本账号。
- **账号名取自官方接口字段**：账号显示名直接读官方接口返回的 `finderUser.nickname`——它和该账号的唯一 ID 在**同一次响应的同一个对象**里返回，天然配对，不可能「名字对、身份错」。不再从页面文字里抓取，也就不会再把界面上的按钮文案（例如「切换视频号 / 取消切换」）误当成账号名（旧版本踩过这个坑）。

## 6. 作品管理

- **本地作品库**：所有账号发布的作品（封面、标题、播放、点赞、评论数等）自动抓到本地保存，之后浏览、搜索、排序**不再请求官方接口**，打开就是毫秒级。
- **批量操作**：勾选多个作品，批量「隐藏（设为仅自己可见）/ 取消隐藏 / 置顶 / 取消置顶」；支持按**发布日期范围**筛选后一键批量隐藏。
- **数据排序**：按发布时间、播放量、点赞、评论、转发、收藏排序，快速找出该隐藏的旧作品、该推流的爆款。
- **省流量防风控**：增量抓取——数据没变化就不重复抓，封面只下一次；顶栏实时显示"今日已请求官方接口 N 次"。
- **每日定时刷新**：每天自动同步一次在线账号的作品数据，也可手动点刷新。

## 7. 省资源、够稳定

- 长期运行经过多轮内存优化（rev11→rev21），可以 7×24 挂机不重启；
- 写操作（回复/隐藏/置顶）自带节流和每日上限，降低账号风控风险；
- 界面字号 大/中/小 三档可调，1080P 小屏也舒适。

## 8. 数据安全

- 账号登录态、数据库、封面图全部存**本机**，不上传云端；
- 版本库（git）不含任何账号数据，配置与登录态目录均已排除并脱敏。

---

**适用**：多账号视频号电商/直播团队，尤其是需要一个"指挥屏"盯全场、多人共用数据的场景。
